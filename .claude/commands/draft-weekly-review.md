# Draft the Monday review from current facts

Read CLAUDE.md and docs/cli.md. Run:

```bash
npm run programmes -- draft-weekly-review
```

Read the generated fact pack. Turn it into an editable draft with source IDs, reporting period, units and missing evidence stated. Save it in drafts/. The session draft is a header brief: read delivery-ledger and the session register before adding attendance details. Never infer social outcomes from delivery volume. Nothing sends.
