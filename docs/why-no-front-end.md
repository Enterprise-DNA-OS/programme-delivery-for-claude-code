# Views without an editing screen

The recurring work is reading records, reconciling delivery and drafting evidence. A coding agent runs those operations through one CLI. Read-only HTML provides a printable week review, capacity sheet and paperwork.

A screen adds mobile attendance collection, offline capture, participant self-service, drag-and-drop scheduling and role-specific access. This base does not provide those. It is for trusted operators using one private database. Enterprise DNA scopes those interfaces and integrations into a customised version when the team needs them.

The benefit is control over fields, units, rules and questions. The responsibility is operating a private database, backing it up and reviewing changes. The agent is the door. The database and evidence remain yours.
