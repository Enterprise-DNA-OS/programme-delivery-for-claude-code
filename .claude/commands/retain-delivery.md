# Extend an evidence retention date

Read CLAUDE.md and docs/cli.md. Run:

```bash
npm run programmes -- retain-delivery <delivery> --until=YYYY-MM-DD --evidence="<retention policy>" --actor=<operator>
```

Read the affected records first. Use only facts supplied by the operator or their source documents. Resolve ambiguity before changing anything. Record the operator label and show the resulting record. Do not claim a report was sent merely because its local milestone was completed.
